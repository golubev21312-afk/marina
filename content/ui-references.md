## Как устроен эффект перехода (№ 4–11), разобран по кадрам

Единственный референс, который прислан целиком — есть весь код.

- `TransitionContext` раздаёт функцию `transitionTo(page)` вниз по дереву
- клик по `<Link>` не переходит сразу: `preventDefault()`, затем `transitionTo` ставит фазу `covering`
- два div-а `.bubbles__first` и `.bubbles__second` размером `250vw` с `border-radius` в половину размера выезжают снизу, распрямляясь в прямоугольник — экран закрыт
- по `onAnimationEnd` с именем `bubble-second-move` вызывается `navigate()` — маршрут меняется, пока не видно
- фаза `holding` держит заливку `--enter-delay`, потом `setTransition(null)` — пузыри уезжают, контент проявляется анимацией `appear`
- новая страница въезжает каскадом: `nav h1` с задержкой `--enter-delay`, `nav ul` — с удвоенной

Нужен `react-router-dom` — сейчас в проекте его нет.

## Важно про стиль

Все референсы — тёмные, неоновые, «айтишные». У «Крафта» палитра кремовая, тёплая, по дереву. Механику берём, оформление переносим в свои цвета: пузыри перехода делаем терракотовыми/хвойными, а не фиолетовыми.
